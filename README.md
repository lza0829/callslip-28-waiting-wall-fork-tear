# 叫号条（Callslip）

银行网点柜面叫号：取号入队 → 叫号推进 → 过号回收/重叫 → 当日队列封口。

- 前端 http://127.0.0.1:6400
- API http://127.0.0.1:11400
- `docker compose up -d --build`

## 等候墙真源口径

全局采纳**以队列表为准**：

- `tickets` 当日 `等候`/`过号` 行是等候墙唯一真源；`wall_snapshots` 只是同事务刷新的加速缓存。
- 读墙时重算真源摘要，与快照逐字段比对：缺失标「未物化」、不一致标「陈旧」，两者都熄灭对齐灯。
- 取号/叫号/过号/重叫/办结/作废/种类启停/切日全部走 `BEGIN IMMEDIATE` 写事务，队列表与快照同提交、同回滚。
- 纠偏入口 `POST /api/等候墙/重放`：只按队列表重放缓存，不改队列表，因此不会被误当作出队成功。
- 回归测试：`cd backend && .venv/bin/python -m tests.test_wall`
